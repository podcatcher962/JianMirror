## English

> See your true, unvarnished self.

**JianMirror** is a situational mirror test built on *Journey to the West* — no verdicts, only reflection: in the same dilemma, which of the pilgrims would you be? The name comes from Laozi's "Jiansu Baopu": *su* is the unbleached silk — your original self.

### 📖 Online

**https://podcatcher962.github.io/JianMirror/**

### ✨ How It Works

- 🪞 **81 mirrors** (one per trial): original passage + plain retelling + a modern dilemma with three choices
- 🧭 **Pilgrim persona**: Wukong·sharp / Tang Monk·rigid / Bajie·smooth / Sha Wujing·steady / White Dragon·enduring
- 📊 **Jiansu Index 0–100**: how much of your true self remains
- 🕯 **One line per mirror**: the trial is yours to take or leave

### 📌 Current Version

Mirror I (the Bone Demon, Ch. 27) is playable. Roadmap: expand to 21 mirrors, then 81.
